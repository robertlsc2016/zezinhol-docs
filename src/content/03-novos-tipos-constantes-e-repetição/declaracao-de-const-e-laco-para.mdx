# Declaração de const e laço para

Nesta seção, abordaremos dois recursos fundamentais para a estruturação e otimização de algoritmos na linguagem Zezinhol: a seção de constantes (`const`) e a estrutura de repetição finita (`para`).

---

## 1. Declaração de Constantes (`const`)

Além da tradicional seção `var` (destinada a variáveis cujos valores mudam ao longo da execução), a linguagem Zezinhol permite utilizar uma seção de constantes.

### O que são Constantes?
As constantes representam **valores fixos**, isto é, dados que são definidos uma única vez e **não devem mudar** durante toda a execução do algoritmo. 

### Regras de Declaração:
* A seção de constantes deve ser obrigatoriamente definida **antes** da seção `var`.
* A estrutura geral de declaração é composta pela palavra reservada `const` seguida do nome da constante e seu valor atribuído:

```zezinhol
const
  NOME_CONSTANTE valor
```

### Exemplo Prático de Utilização:
```zezinhol
algoritmo exemploConstantes
const
  MAX = 75
var
  i: inteiro
  s: string
início
  s <- "Limite"
  i <- MAX
  escreva(i, " ", s)
fim algoritmo
```

### Por que utilizar Constantes?
* **Organização:** O código fica mais limpo e legível.
* **Manutenibilidade:** Caso o valor fixo precise ser alterado no futuro (por exemplo, um limite máximo ou uma taxa), ele é modificado em um único lugar (no topo do código), evitando alterações manuais espalhadas por todo o corpo do algoritmo.
* **Segurança:** Tentar alterar o valor de uma constante no corpo do algoritmo (como fazer `MAX <- 100`) é um erro e **não deve ser feito**, pois a essência da constante é a imutabilidade.

## 2. Estrutura de Repetição com Contador (`para`)

A estrutura `para` é um laço de repetição utilizado quando a **quantidade de repetições é conhecida previamente** ou pode ser determinada com exatidão antes do laço começar.

### Quando utilizar?
É bastante útil em situações em que precisamos percorrer uma sequência fixa de valores, como contar de 1 até 10, processar uma lista de tamanho fixo ou acessar individualmente todos os caracteres de uma string.

### Sintaxe Geral:
```zezinhol
para variavel de valorInicial até valorFinal faça
  comandos
fim para
```

### Funcionamento Interno:
* Na linguagem Zezinhol, a estrutura `para` trabalha obrigatoriamente com uma **variável de controle** (geralmente um contador como `i`) que recebe o `valorInicial` e é **incrementada automaticamente de 1 em 1** a cada repetição.
* Por esse comportamento, a estrutura `para` deve ser entendida como uma forma abreviada e mais limpa de escrever uma estrutura `enquanto` com incremento unitário fixo.

### Equivalência com o laço `enquanto`:
Por exemplo, o bloco utilizando o `para`:
```zezinhol
para i de 1 até 5 faça
  escreva(i)
fim para
```
Possui funcionamento exatamente equivalente à seguinte estrutura `enquanto`:
```zezinhol
i <- 1
enquanto i <= 5 faça
  escreva(i)
  i <- i + 1
fim enquanto
```

### Regras Importantes do `para`:
* **Incremento Fixo:** Não se deve tentar definir outro valor de incremento (como passos de 2 em 2) dentro da própria estrutura `para`. Caso o controle da repetição exija uma atualização diferente de 1, deve-se obrigatoriamente utilizar a estrutura `enquanto`.
* **Controle de Strings:** Como as strings são sequências indexadas de caracteres, a estrutura `para` encaixa-se perfeitamente para percorrê-las posição por posição.

## 3. Exemplo Completo Prático

Abaixo, apresentamos um algoritmo completo que une o conceito de leitura textual, o uso da estrutura `para` para varcorer uma string, a manipulação da tabela ASCII e o armazenamento em variáveis lógicas:

```zezinhol
algoritmo contaMaiusculas
var
  palavra: string
  i, qtd: inteiro
  c: caracter
  ehMaiuscula: lógico
início
  qtd <- 0
  leia(palavra)
  
  para i de 1 até tamanho(palavra) faça
    c <- palavra[i]
    ehMaiuscula <- (c >= 'A') e (c <= 'Z')
    
    se ehMaiuscula então
      qtd <- qtd + 1
    fim se
  fim para
  
  escreva("Quantidade de maiúsculas: ", qtd)
fim algoritmo
```

### O que acontece neste exemplo?
1. O algoritmo declara variáveis para armazenar a palavra, índices de controle, o caractere atual e um sinalizador lógico.
2. A estrutura `para` percorre a string do primeiro caractere (`1`) até o último (`tamanho(palavra)`).
3. A cada ciclo, o caractere da posição atual é isolado, avaliado por operadores relacionais com base na tabela ASCII e o resultado lógico alimenta a condição que incrementa o contador de letras maiúsculas.
