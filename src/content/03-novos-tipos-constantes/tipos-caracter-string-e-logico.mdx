# Tipos: caracter, string e logico

A partir do terceiro volume, a linguagem Zezinhol passa a permitir a manipulacao de valores textuais e logicos. A declaracao desses tipos segue a mesma ideia dos tipos numericos: as variaveis devem ser declaradas na secao var antes de serem utilizadas.

## 1. Tipo logico

O tipo logico e utilizado para representar valores logicos. 
Uma variavel logica pode armazenar apenas dois valores:
* verdadeiro
* falso

Esse tipo e muito util quando queremos guardar o resultado de uma condicao. Variaveis logicas tambem podem ser utilizadas diretamente em estruturas condicionais. Tambem e possivel combinar valores logicos utilizando os operadores logicos e, ou e nao.

## 2. Tipo caracter

O tipo caracter e utilizado para armazenar um unico caractere. 
Um caractere pode ser uma letra, um digito, um simbolo ou ate mesmo o espaco em branco. 
Na linguagem Zezinhol, valores do tipo caracter devem ser escritos entre aspas simples.

Exemplos de caracteres:
* 'A'
* 'z'
* '7'
* '+'

O tipo caracter pode ser usado em leituras, escritas, atribuicoes, comparacoes e expressoes que envolvam funcoes proprias para caracteres.

## 3. Tipo string

Cadeias de caracteres, chamadas de strings, sao utilizadas para representar uma sequencia de caracteres. 
Uma string pode armazenar nomes, frases, palavras, textos curtos ou qualquer outra informacao textual. 
Uma string deve ser escrita entre aspas duplas. Isso a diferencia das variaveis e das palavras reservadas da linguagem.

Exemplos de strings:
* "Jose"
* "Algoritmos 1"
* "" (string vazia)

A funcao tamanho() permite saber quantos caracteres existem em uma string.
