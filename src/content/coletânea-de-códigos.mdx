* **Autor:** Robert Luiz

```zezinhol

    MAX = 100
tipos
    TMeuVetor = vetor [1..MAX] de real

var
    meuVetor: TMeuVetor

    procedimento preencheVetor(ref v: TMeuVetor)

        i : inteiro

    início
        para i de 1 até MAX faça
            v[i] <- trunca( ( aleatorio() *  (100 - 1 + 1) ) + 1)

    var
        i, j : inteiro
        aux : real

                    aux <- v[j]
                    v[j] <- v[j+1]
                    v[j+1] <- aux
                fim se
            fim para
        fim para
    fim procedimento
```

### Exercício 8

* **Enunciado:** Faça o algoritmo de uma função que receba um número inteiro e retorne uma string contendo sua representação em binário.

```zezinhol
    j, numerador: inteiro
    s_acc, aux_s_acc : string
início

        retorne "0"
    fim se

    numerador <- n
    aux_s_acc <- ""
    s_acc <- "" 

    enquanto (numerador DIV 2 <> 0) faça
        se (numerador MOD 2 = 1) então
            aux_s_acc <- aux_s_acc + "1"
        senão
            aux_s_acc <- aux_s_acc + "0"
        fim se
        numerador <- numerador DIV 2
    fim enquanto    

    aux_s_acc <- aux_s_acc + "1"

    j <- tamanho(aux_s_acc)

    enquanto j >= 1 faça
        s_acc <- s_acc + aux_s_acc[j]
        j <- j - 1
    fim enquanto

    retorne s_acc
fim função
```

```zezinhol
PROCEDIMENTO leiaIntervalo(REF n: INTEIRO; min, max: REAL)

FIM PROCEDIMENTO
```

### Exercício 12

* **Enunciado:** Faça o algoritmo de uma função string que receba dois parâmetros: um caracter ce um número inteiro n, e retorne a string que tenha sequencialmente todos os n caracteres imprimíveis da tabela ASCII padrão a partir de c. Se houver menos que n caracteres nesta condição, não veja isto como problema e retorne a string com esse tamanho menor. Se n for negativo considere todos os n caracteres (anteriores) até c, ou seja, c será o último caracter da string.
* **Autor:** Robert Luiz

```zezinhol
funcao alfascii(c: caracter, n: inteiro): string
var
    i: inteiro
    str: string
início
    str <- c

    se (n = 0) entao
        retorne ""
    fim se

    se (n > 0) entao
        para i de 1 até (n - 1) faça
            se (asc(c) + i >= 32 E asc(c) + i <= 126) entao
                str <- str + chr(asc(c) + i)
            fim se
        fim para
        retorne str
    fim se

    se (n < 0) entao
        para j de (asc(c) + n - 1) até asc(c) faça
            se (j >= 32 E j <= 126) entao
                str <- str + chr(j)
            fim se
        fim para
        retorne str
    fim se
fim funcao
```

<details>
<summary>Resolução IA</summary>

```zezinhol
função alfascii(c: caracter, n: inteiro): string
var
    i, codigo, limite: inteiro
    str: string
início
    str <- ""

    // 1º Cenário: n é positivo (captura de 'c' para a frente)
    se n > 0 então
        para i de 1 até n faça
            codigo <- asc(c) + i - 1
            
            // Filtra exclusivamente os caracteres imprimíveis da tabela ASCII
            se codigo >= 32 e codigo <= 126 então
                str <- str + chr(codigo)
            fim se
        fim para
    fim se

    // 2º Cenário: n é negativo (captura de trás para a frente, terminando em 'c')
    se n < 0 então
        // Inverte o sinal de n para o laço 'para' conseguir rodar positivamente
        limite <- n * -1
        
        para i de 1 até limite faça
            // A matemática aqui recua as posições e vem somando até chegar no próprio 'c'
            codigo <- asc(c) + n + i
            
            se codigo >= 32 e codigo <= 126 então
                str <- str + chr(codigo)
            fim se
        fim para
    fim se

    // Se n for exatamente 0, os blocos são ignorados e a string retorna vazia
    retorne str
fim função
```
