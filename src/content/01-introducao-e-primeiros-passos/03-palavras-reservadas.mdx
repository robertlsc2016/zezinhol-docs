# Palavras Reservadas

Na linguagem Zezinhol, assim como em qualquer linguagem de programação, existem termos que possuem significados especiais e funções específicas dentro da sintaxe. Estas são chamadas de **Palavras Reservadas**.

Como o próprio nome sugere, essas palavras são "reservadas" pelo sistema para controlar o fluxo do programa, definir estruturas e declarar tipos. Portanto, **elas nunca podem ser utilizadas como nomes de variáveis, constantes, funções ou registros**.

---

## Lista de Palavras Reservadas por Categoria

Para facilitar o estudo, as palavras reservadas da linguagem Zezinhol (apresentadas ao longo dos volumes da disciplina) foram divididas por suas categorias de uso:

### 1. Estrutura Base e Blocos
* `algoritmo` : Define o nome do programa.
* `const` : Inicia o bloco de declaração de constantes fixas.
* `tipos` : Inicia o bloco de declaração de estruturas heterogêneas.
* `var` : Inicia o bloco de declaração de variáveis.
* `início` : Marca o começo do corpo de execução do algoritmo.
* `fim algoritmo` : Marca o encerramento do programa.

### 2. Tipos de Dados
* `inteiro` : Tipo numérico sem casas decimais.
* `real` : Tipo numérico com casas decimais (ponto flutuante).
* `caracter` : Tipo textual que armazena apenas um símbolo.
* `string` : Tipo textual que armazena uma cadeia de símbolos/texto.
* `lógico` : Tipo booleano que armazena estados de verdade.
* `registro` / `fim registro` : Estrutura de dados heterogênea.
* `vetor` : Estrutura de dados homogênea e indexada.
* `de` : Usado na declaração de vetores e registros (ex: vetor [1..10] de inteiro).

### 3. Valores Lógicos
* `verdadeiro` : Estado lógico positivo.
* `falso` : Estado lógico negativo.

### 4. Controle de Fluxo e Repetição
* `se` / `então` / `senão` / `fim se` : Estrutura condicional de tomada de decisão.
* `enquanto` / `faça` / `fim enquanto` : Estrutura de repetição baseada em condição.
* `para` / `de` / `até` / `fim para` : Estrutura de repetição finita com contador.

### 5. Operadores Lógicos e Matemáticos Especiais
* `e` : Operador lógico de conjunção (AND).
* `ou` : Operador lógico de disjunção (OR).
* `não` : Operador lógico de negação (NOT).
* `div` : Retorna a parte inteira de uma divisão.
* `mod` : Retorna o resto de uma divisão inteira.

### 6. Operações de Nível de Bit
* `bit e`, `bit ou`, `bit nao`, `bit xor` : Operadores lógicos aplicados bit a bit.
* `shl`, `shr` : Deslocamento de bits para a esquerda e para a direita.
* `rotd`, `rote` : Rotação de bits para a direita e para a esquerda.

## Regra de Ouro (Provas e Manuscritos)

Conforme a documentação oficial estabelecida para a disciplina de Algoritmos 1, ao escrever algoritmos na linguagem Zezinhol **à mão (em papel, provas ou listas de exercícios físicas)**, é uma regra explícita que **todas as palavras reservadas devem ser sublinhadas**. 

Isso ajuda a organizar a leitura visual do código e permite diferenciar facilmente o que é um comando nativo da linguagem do que é um identificador criado pelo aluno.
