# Funções Nativas (Reservadas)

A linguagem Zezinhol possui um conjunto de funções nativas (ou embutidas) que já vêm prontas para uso. Elas servem para facilitar tarefas comuns do dia a dia da programação, como manipulação de textos (strings), conversão de caracteres (tabela ASCII) e operações matemáticas básicas.

Abaixo, detalhamos cada uma das funções reservadas disponíveis.

---

## 1. Manipulação de Textos e Caracteres

### `tamanho(s : string) : inteiro`
Retorna a quantidade de caracteres contidos em uma variável do tipo `string`. É extremamente útil para determinar o limite final em laços de repetição ao varrer uma palavra letra por letra.

**Exemplo:**
```zezinhol
algoritmo medePalavra
var
  palavra: string
  qtdLetras: inteiro
início
  palavra <- "Zezinhol"
  
  qtdLetras <- tamanho(palavra)
  
  // O resultado será 8
  escreva("A palavra possui ", qtdLetras, " letras.")
fim algoritmo

```

### `asc(c : caracter) : inteiro`

Converte um caractere no seu valor numérico inteiro correspondente, de acordo com a tabela ASCII. Muito utilizada para fazer contas matemáticas com letras e números textuais, como converter a string '1' no número 1 subtraindo `asc('0')`.

**Exemplo:**

```zezinhol
algoritmo codigoAscii
var
  letra: caracter
  codigo: inteiro
início
  letra <- 'A'
  
  codigo <- asc(letra)
  
  // O código ASCII da letra 'A' maiúscula é 65
  escreva("O codigo numérico de ", letra, " e: ", codigo)
fim algoritmo

```

### `chr(n : inteiro) : caracter`

Faz o inverso da função `asc()`: recebe um valor numérico inteiro e o converte no seu respectivo caractere na tabela ASCII.

**Exemplo:**

```zezinhol
algoritmo caractereAscii
var
  codigo: inteiro
  letra: caracter
início
  codigo <- 66
  
  letra <- chr(codigo)
  
  // O código 66 corresponde à letra 'B'
  escreva("O codigo 66 representa o caractere: ", letra)
fim algoritmo

```

## 2. Operações Matemáticas e Sorteios

### `aleatorio()`

Função utilizada para gerar valores aleatórios (sorteios) durante a execução do algoritmo. Ideal para simular dados, jogos, ou preencher vetores com valores randômicos de forma automática.

**Exemplo:**

```zezinhol
algoritmo sorteio
var
  numeroSorteado: inteiro
início
  // A atribuição gera um valor randômico
  numeroSorteado <- aleatorio()
  
  escreva("O numero sorteado foi: ", numeroSorteado)
fim algoritmo

```

### `trunca(v : real) : inteiro`

Realiza o truncamento numérico de um valor real. Diferente do arredondamento (que pode jogar o valor para o inteiro mais próximo), o truncamento simplesmente "corta" e descarta toda a parte decimal (após a vírgula), mantendo apenas a parte inteira do número.

**Exemplo:**

```zezinhol
algoritmo cortaDecimais
var
  valorReal: real
  valorInteiro: inteiro
início
  valorReal <- 9.875
  
  valorInteiro <- trunca(valorReal)
  
  // O valor armazenado será apenas 9 (a parte .875 é descartada)
  escreva("Valor original: ", valorReal)
  escreva("Valor truncado: ", valorInteiro)
fim algoritmo

```
