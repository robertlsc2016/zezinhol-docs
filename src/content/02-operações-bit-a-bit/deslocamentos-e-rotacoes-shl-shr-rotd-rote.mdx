# Deslocamentos e Rotações

Na linguagem Zezinhol, é possível manipular a posição dos bits de um número inteiro utilizando operadores de deslocamento (shift) e rotação. As operações alteram a representação binária internamente. Para todos os exemplos a seguir, considera-se a representação em 8 bits.

---

## 1. shl (Deslocamento para a esquerda)

Desloca os bits para a esquerda. Deslocar os bits significa mover todos os bits para a esquerda. Os bits que saem são descartados e as posições vazias são preenchidas sempre com 0.

### Sintaxe
inteiro shl número de bits

### Exemplo
n = 20 = 00010100
n shl 1 = 00101000 = 40
n shl 2 = 01010000 = 80
n shl 4 = 01000000 = 64

---

## 2. shr (Deslocamento para a direita)

Desloca os bits para a direita. Deslocar os bits significa mover todos os bits para a direita. Os bits que saem são descartados e as posições vazias são preenchidas sempre com 0.

### Sintaxe
inteiro shr número de bits

### Exemplo
n = 20 = 00010100
n shr 1 = 00001010 = 10
n shr 2 = 00000101 = 5
n shr 3 = 00000010 = 2

---

## 3. rotd (Rotação para a direita)

Rotaciona os bits para a direita. Rotacionar os bits significa mover todos os bits para a direita sem perda de informação. O bit que sai de uma extremidade retorna pela outra.

### Sintaxe
inteiro rotd número de bits

### Exemplo
n = 9 = 00001001
n rotd 1 = 10000100 = 132

---

## 4. rote (Rotação para a esquerda)

Rotaciona os bits para a esquerda. Rotacionar os bits significa mover todos os bits para a esquerda sem perda de informação. O bit que sai de uma extremidade retorna pela outra.

### Sintaxe
inteiro rote número de bits

### Exemplo
n = 201 = 11001001
n rote 1 = 10010011 = 147
