# Algoritmos de Busca e Ordenação

A manipulação eficiente de dados em estruturas lineares exige o conhecimento de algoritmos clássicos de localização (busca) e organização (ordenação). A seguir, detalhamos as implementações e conceitos fundamentais para estes algoritmos na linguagem Zezinhol.

---

## 1. Algoritmos de Busca

A busca consiste em varrer uma estrutura linear à procura de um valor alvo conhecido como chave [cite: 2].

### 1.1 Busca Linear
Percorre o vetor sequencialmente a partir do primeiro índice, checando os limites estruturais do tamanho e a igualdade da chave a cada iteração [cite: 2].

```zezinhol
i <- 1
enquanto i <= N e v[i] != chave faça
  i <- i + 1
fim enquanto

se i <= N então
  escreva("O elemento esta na posicao", i)
senão
  escreva("O elemento nao esta no vetor.")
fim se
```

### 1.2 Busca Linear com Sentinela
Para otimizar o laço linear tradicional, expande-se o vetor adicionando uma posição fictícia logo após o tamanho preenchido ($N+1$) para clonar a chave buscada [cite: 2]. Isso elimina a necessidade de testar o limite de posições (`i <= N`) dentro do laço de repetição, economizando processamento [cite: 2].

```zezinhol
leia(x)
v[M + 1] <- x
i <- 1

enquanto v[i] != x faça
  i <- i + 1
fim enquanto

se i <= M então
  escreva("Achado em", i)
senão
  escreva("Nao existe")
fim se
```

### 1.3 Busca Binária
A Busca Binária funciona dividindo consecutivamente a região de busca pela metade [cite: 2]. 

* **IMPORTANTE (pré-condição):** A busca binária somente funciona corretamente quando o vetor está **previamente ordenado** [cite: 2]. Se o vetor estiver desorganizado, a lógica de corte de limites falhará completamente e o elemento não será localizado [cite: 2].

```zezinhol
esq <- 1
dir <- N
achou <- falso

enquanto esq <= dir e não achou faça
  meio <- (esq + dir) div 2
  se v[meio] = x então
    achou <- verdadeiro
  senão
    se x > v[meio] então
      esq <- meio + 1
    senão
      dir <- meio - 1
    fim se
  fim se
fim enquanto
```

## 2. Algoritmos de Ordenação

A ordenação organiza os elementos de um vetor em uma ordem específica (crescente ou decrescente).

### 2.1 Selection Sort (Seleção Direta)
Varre o vetor selecionando o menor elemento restante e colocando-o na posição ordenada atual [cite: 2].

```zezinhol
para i de 1 até N - 1 faça
  menor <- i
  para j de i + 1 até N faça
    se v[j] < v[menor] então
      menor <- j
    fim se
  fim para
  aux <- v[i]
  v[i] <- v[menor]
  v[menor] <- aux
fim para
```

### 2.2 Bubble Sort (Bolha)
Compara elementos adjacentes empurrando os maiores para o topo, interrompendo as voltas quando nenhuma troca for detectada [cite: 2].

```zezinhol
trocou <- verdadeiro
enquanto trocou faça
  trocou <- falso
  para i de 1 até N - 1 faça
    se v[i] > v[i + 1] então
      aux <- v[i]
      v[i] <- v[i + 1]
      v[i + 1] <- aux
      trocou <- verdadeiro
    fim se
  fim para
fim enquanto
```

### 2.3 Insertion Sort (Inserção Direta)
Insere cada elemento ordenadamente na sublista inicial já organizada [cite: 2].

```zezinhol
para i de 2 até N faça
  aux <- v[i]
  j <- i - 1
  enquanto j > 0 e v[j] > aux faça
    v[j + 1] <- v[j]
    j <- j - 1
  fim enquanto
  v[j + 1] <- aux
fim para
```
