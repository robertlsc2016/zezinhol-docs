# Sorteios Numéricos (`aleatorio()`, `trunca()`)

Em muitas situações computacionais, precisamos que o próprio algoritmo gere valores sem a intervenção direta do usuário através do teclado (por exemplo, para testes automatizados ou simulações). Para isso, a linguagem Zezinhol disponibiliza duas funções fundamentais: `aleatorio()` e `trunca()`.

---

## 1. Funções Primitivas de Base

### `aleatorio()`
* **O que faz:** Função que retorna um número real sorteado uniformemente no intervalo fechado $[0; 1]$.
* **Comportamento estatístico:** Garante chances iguais de distribuição dentro da faixa unitária.

### `trunca(x)` (ou `trunca()`)
* **O que faz:** Recebe um número real por parâmetro e devolve estritamente a sua parte inteira, mapeando o resultado como um tipo inteiro.
* **Objetivo matemático:** Remove a sobra decimal flutuante sem realizar arredondamento, isolando apenas a unidade inteira.

---

## 2. Fórmulas de Mapeamento Estatístico

A partir do comportamento estatístico uniforme dessas funções primitivas, deduzimos as expressões matemáticas necessárias para mapear os sorteios dentro de limites customizados $[a; b]$.

### 2.1 Sorteio de Números Reais entre $a$ e $b$
Para espalhar uniformemente um valor real contínuo no intervalo desejado:

```zezinhol
x <- aleatorio() * (b - a) + a
```

### 2.2 Sorteio de Números Inteiros entre $a$ e $b$
Para garantir que o número sorteado caia exatamente sobre um valor discreto inteiro, com chances iguais para todos os elementos do intervalo:

```zezinhol
x <- trunca(aleatorio() * (b - a + 1)) mod (b - a + 1) + a
```
*(Também expresso equivalentemente como: `x <- aleatorio() * (b - a + 1)`, seguido de `x <- trunca(x) mod (b - a + 1)` e `x <- x + a`)*.

### 2.3 Sorteio de Números Reais com Quantidade Fixa ($k$) de Casas Decimais entre $a$ e $b$
Caso precisemos simular valores monetários ou de medição precisa com exatamente $k$ casas decimais, utilizamos a seguinte fórmula:

```zezinhol
x <- trunca(((b - a) * 10^k + 1) * aleatorio()) mod trunca((b - a) * 10^k + 1) / 10^k + a
```

---

## 3. Desmistificando a Lógica (Passo a Passo)

À primeira vista, a fórmula de casas decimais fixas parece complexa, mas a sua intuição intermediária é simples:
1. **Multiplicação pela escala:** Multiplicamos a amplitude $(b - a)$ por $10^k$ para transformar temporariamente as casas decimais que queremos sortear em unidades inteiras (por exemplo, transformar o intervalo real $1.25$ no número inteiro $125$).
2. **Truncamento (`trunca`):** Remove-se a sobra decimal flutuante para isolar o número estritamente inteiro.
3. **Resto da Divisão (`mod`):** Garante com segurança matemática que o valor inteiro gerado esteja cravado dentro do limite discreto correto.
4. **Divisão por $10^k$:** A vírgula é arrastada de volta para a esquerda, devolvendo as casas decimais exatas.
5. **Deslocamento Final ($+a$):** Soma-se o limite inicial $a$ para empurrar o intervalo (que começava em zero) para o ponto de partida correto.

### Exemplo Prático Detalhado:
Imagine que queremos sortear um número real entre $a = 1$ e $b = 4$ com exatamente $k = 2$ casas decimais. Substituindo os limites, a amplitude ampliada se torna: $(4 - 1) 	imes 10^2 + 1 = 3 	imes 100 + 1 = 301$.

Se a função `aleatorio()` retornar internamente o valor real `0.74259...`, acompanhe a linha de produção matemática que o algoritmo executa passo a passo:
1. **Multiplicação pela escala:** $301 \times 0.74259... = 223.51959...$
2. **Truncamento (`trunca`):** Isola-se o inteiro $\rightarrow 223$
3. **Resto da Divisão (`mod 301`):** $223 \bmod 301 = 223$
4. **Divisão por $10^k$:** $223 / 100 = 2.23$
5. **Deslocamento Final (`+1`):** $2.23 + 1 = 3.23$ (número sorteado final)
---

## 4. Exemplo Completo em Algoritmo

Abaixo, um exemplo prático unificando registros, preenchimento dinâmico com sorteio formatado com $2$ casas decimais e ordenação:

```
zezinhol
algoritmo SistemaSorteioEstudantes
const
  MAX = 40
tipos
  Aluno registro
    nome: string
    numero: real
  fim registro
var
  turma: vetor [1..MAX] de Aluno
  aux: Aluno
  i, j, menor: inteiro
início
  // Passo 1: Leitura dos nomes e sorteio dos numeros (1 a 100 com 2 casas decimais)
  para i de 1 até MAX faça
    escreva("Digite o nome do aluno ", i, ": ")
    leia(turma[i].nome)
    
    // Aplicando a formula deduzida para k = 2 casas decimais no intervalo [1; 100]
    turma[i].numero <- trunca(((100 - 1) * 10^2 + 1) * aleatorio()) mod trunca((100 - 1) * 10^2 + 1) / 10^2 + 1
  fim para

  // Passo 2: Ordenacao dos registros baseando-se no numero sorteado (Selection Sort)
  para i de 1 até MAX - 1 faça
    menor <- i
    para j de i + 1 até MAX faça
      se turma[j].numero < turma[menor].numero então
        menor <- j
      fim se
    fim para
    aux <- turma[i]
    turma[i] <- turma[menor]
    turma[menor] <- aux
  fim para

  // Passo 3: Escrita dos resultados ordenados
  escreva("--- Lista Classificada por Numero Sorteado ---")
  para i de 1 até MAX faça
    escreva("Aluno: ", turma[i].nome, " - Numero Sorteado: ", turma[i].numero)
  fim para
fim algoritmo
```
