# Vetores Unidimensionais e Matrizes

Até os momentos iniciais de aprendizado, trabalhamos com tipos simples, onde cada variável armazena um único valor por vez [cite: 2]. No entanto, quando precisamos lidar com coleções de dados, utilizamos os **vetores** (ou arranjos), que são agregados de variáveis do mesmo tipo-base [cite: 2]. Além disso, a linguagem permite estender essas estruturas para formar tabelas multidimensionais conhecidas como **matrizes** [cite: 2].

---

## 1. Tipos de Dados Estruturados Homogêneos: Vetores

Os vetores representam coleções lineares de elementos do mesmo tipo [cite: 2]. 

### 1.1 Capacidade versus Tamanho
Para a correta construção de algoritmos utilizando vetores, é vital discernir dois conceitos fundamentais aplicados a estruturas lineares [cite: 2]:
* **Capacidade:** Representa o limite máximo absoluto de posições alocadas na memória para o vetor [cite: 2]. Ela é definida estritamente na seção de declaração (geralmente utilizando uma constante) e **não pode ser modificada** com o programa em execução [cite: 2].
* **Tamanho:** Representa a quantidade real de posições que estão preenchidas com dados úteis e válidos em um determinado instante do algoritmo [cite: 2]. O tamanho é dinâmico (varia de 0 até o limite da capacidade) e é monitorado por variáveis de controle (contadores) gerenciadas pelo programador [cite: 2].

### 1.2 Exemplo Prático de Declaração e Preenchimento de um Vetor

```zezinhol
algoritmo ExemploVetor
const
  CAPACIDADE = 100
var
  v: vetor [1..CAPACIDADE] de real
  i, tamanho: inteiro
início
  tamanho <- 0
  para i de 1 até 10 faça
    leia(v[i])
    tamanho <- tamanho + 1
  fim para
fim algoritmo
```

## 2. Matrizes (Vetores de Vetores)

Na linguagem Zezinhol, matrizes não existem como uma estrutura primitiva isolada [cite: 2]. Uma matriz é modelada estritamente como um **vetor de vetores** [cite: 2].

### 2.1 Matrizes Bidimensionais
Uma matriz bidimensional pode ser visualizada como uma tabela clássica composta por linhas e colunas organizadas geometricamente [cite: 2]. Veja a representação visual da indexação estrutural de uma matriz de 3 linhas e 4 colunas [cite: 2]:

| Coluna 1 | Coluna 2 | Coluna 3 | Coluna 4 |
| :--- | :--- | :--- | :--- |
| `[1,1]` [cite: 2] | `[1,2]` [cite: 2] | `[1,3]` [cite: 2] | `[1,4]` [cite: 2] |
| `[2,1]` [cite: 2] | `[2,2]` [cite: 2] | `[2,3]` [cite: 2] | `[2,4]` [cite: 2] |
| `[3,1]` [cite: 2] | `[3,2]` [cite: 2] | `[3,3]` [cite: 2] | `[3,4]` [cite: 2] |

* No mapeamento acima, o **primeiro índice** localiza estritamente a linha da tabela, enquanto o **segundo** localiza a coluna [cite: 2].

### 2.2 Dimensões Maiores e Extrapolação
A grande vantagem dessa abordagem em cadeia é que, para criar estruturas ainda maiores e de outras dimensões (como cubos tridimensionais ou hipercubos), basta continuar encadeando definições sequencialmente utilizando a sintaxe de `vetor de vetor de vetor de...` [cite: 2]. A indexação segue a mesma ordem encadeada de colchetes simples para cada dimensão isolada [cite: 2].

### 2.3 Exemplo Prático de Matriz Tridimensional

```zezinhol
algoritmo ExemploMatrizTri
var
  m: vetor [1..10] de vetor [-5..5] de vetor [0..3] de real
  i, j, k: inteiro
início
  para i de 1 até 10 faça
    para j de -5 até 5 faça
      para k de 0 até 3 faça
        leia(m[i][j][k])
      fim para
    fim para
  fim para
fim algoritmo
```
